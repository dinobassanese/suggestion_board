Two complete example brands. To try one:

1. Open the folder of the example you like (bakery or studio).
2. Copy everything inside it into the "branding" folder, replacing what is there.
3. Restart the app (or upload the files to GitHub if it is online).
4. Change the name, colors, logo and wording to your own.

The names and logos here are invented, for demonstration only.
Details on every setting: docs/BRANDING.md
